# Decision 0011: `m4-test-planet` archetype

## Status
Accepted

## Decision
Add `m4-test-planet` as a rendering testbed archetype used by `pnpm dev` for M4.

## Rationale
- Stable known-good Earth-sized planet around a Sun-like star for rendering and camera iteration.
- Keeps rendering development independent from showcase taxonomy tuning.
- Explicitly not a showcase target; it is a development fixture archetype.
